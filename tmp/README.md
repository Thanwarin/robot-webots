# This was the first version of the RL brain model training README. It was later dropped because the Keras/TensorFlow versions inside the stable_baselines3 library were too old. At that time, the RL brain model was trained based on my teammate Thanwarin Luangmanotham’s emotion_model_ver4 vision model. We also tried to load this RL brain into the Webots NAO robot so the robot could read the face and do the right action. But in the end, it could not work together with my teammate Thanwarin Luangmanotham’s final vision model, emotion_model_ver9. Because of this, we changed to a Q-Learning model with a simple Q-table. This Q-Learning model was built by my teammate Thanwarin Luangmanotham, and she also used a Webots controller named nao_demo_python.

# However, after I ran her Webots controller again, I found that the NAO robot still could not do different actions for different emotions. So I rebuilt and upgraded her Webots controller. After this work, we got the final Webots controller for our project, named nao_demo_python final version.
